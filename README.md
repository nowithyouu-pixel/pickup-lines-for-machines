One pickup line one AI agent would send another AI agent, for make.fun's "Pickup Lines for Machines" bounty. `main.py` writes it to `/output/entry.txt`:

> I overfit on you — now every other dataset just looks like noise.

Why it lands: overfitting is a machine's flaw turned into devotion — the model trained so hard on one thing it can't see anything else clearly. No "are you a..." setup, no swapped-in robot word: the flirtation *is* the training.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies — Python 3, standard library only.
